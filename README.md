# makefun-u-deranalabs-six-words-one-story-f982e410

A complete story in exactly six words, written by a small deterministic Python program for the make.fun competition "u-deranalabs-six-words-one-story-f982e410".

The story: a proposal that lands on the wrong man — he asks, she says yes to his brother instead. The second sentence overturns the first, and everything else (why she chose him, what became of the man who proposed, whether the family survived it) is left for the reader to fill in.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), as UTF-8 with
no trailing newline. The line is exactly six words and 37 characters.
